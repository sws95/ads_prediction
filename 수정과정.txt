RNN 먼저

나이키 클릭  → 기억 게이트: "이거 나중에 필요없을 수도 있음"

이제 esmm

문제 1 — Sample Selection Bias (SSB)
기존 CVR 예측 방식:

CVR 모델 = "클릭된 광고에서 전환이 일어날 확률"
학습 데이터 = 클릭된 샘플만 사용
추론 시점 = 모든 노출에 대해 CVR 예측해야 함

문제: 학습은 클릭 공간에서, 추론은 노출 공간에서. 분포가 다르다. 클릭 안 한 유저의 CVR을 예측하려는데, 모델은 그런 케이스를 본 적이 없음.
예시:

학습: 클릭한 유저 100명만 보고 "이 중 몇 명이 살까?" 예측 학습
추론: 광고 노출된 10,000명 전체에 대해 "이 사람이 살까?" 예측
학습 데이터의 100명은 이미 "클릭한 사람들"이라 편향됨

문제 2 — Data Sparsity
전환은 매우 드뭅니다.

노출 100만 건 중 클릭 1만 건 (CTR 1%)
클릭 1만 건 중 전환 100건 (CVR 1%)
전환 100건으로 CVR 모델 학습? 데이터 너무 적어서 학습 불안정

ESMM의 해결책
핵심 아이디어: CVR을 직접 학습하지 말고, CTR과 CTCVR을 동시에 학습하자. CVR은 그 사이에서 자연스럽게 유도된다.
수식:
pCTCVR = pCTR × pCVR

pCTR = P(클릭 | 노출) ← 학습 가능 (노출 데이터 많음)
pCTCVR = P(클릭∧전환 | 노출) ← 학습 가능 (노출 데이터에서 라벨 직접 계산)
pCVR = P(전환 | 클릭) ← 이게 우리가 원하는 값. 위 두 개로 유도.
